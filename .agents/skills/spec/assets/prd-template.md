# PRD template

Write to `docs/prd-<kebab-slug>.md`. Sections may be one bullet if that is all the truth there is — do not pad.

```markdown
# PRD: <Title>

## Problem
<one paragraph — why this matters>

## Goals / Non-goals
- Goals:
  - …
- Non-goals:
  - …

## Users
<who, what they need>

## Happy path
<numbered steps a user takes>

## Edge cases
<bullets>

## Validation rules
<bullets — field-level, be specific>

## Error states
<bullets — how the UI surfaces failure>

## Acceptance criteria
- [ ] <observable, copy-paste-able>
- [ ] …
```
